# 洗衣房管理系统

手机、电脑都能用的洗衣房管理系统：开单登记、取货、订单查询、客户管理、经营数据、标签打印，分店长 / 店员两种权限。

- 网页版，无需安装 App：电脑用浏览器，手机连店里 WiFi 直接打开（可“添加到主屏幕”像 App 一样使用）
- 一台电脑运行即可，数据保存在本机一个文件里，每天自动备份
- 不依赖外网，所有页面资源都在本地，国内网络环境稳定可用

## 功能

| 功能 | 说明 |
|---|---|
| 开单 | 输入编码（4 位或 6 位数字）和姓名；老客户输入编码/姓名即可联想选择；编码可以多人共用，一个编码有多位客户时弹出姓名选择（也可选“新客户”），同名客户也可以有不同编码；点选品类（点一下加 1 件，长按输入数量）；记录送来时间、备注、金额（可选）；点“开单”后弹出打印选项 |
| 取货 | 输入编码 / 姓名 / 单号模糊查找在店衣物；输入完整编码自动勾选该客户全部待取订单（编码多人共用时按姓名分组，由店员勾选）；一次可取多单；记录取走时间和经办人 |
| 订单查询 | 按姓名、编码、单号、状态、品类、送来/取走日期、是否超期筛选；导出 Excel |
| 客户管理 | 客户档案；每位客户“什么时间送来了什么、什么时间取走”的完整记录；为老客户快速开单；按包期会员/普通会员筛选 |
| 包期会员 | 设为包期会员后编码前自动加 88（1234 → 881234）；每周（周一至周日，按送来时间）额度默认衣物和浴巾合计 9 件、鞋子 1 双（同一项额度里的品类合并计算，可在系统设置里调整）；开单时不提示超额，店长在“客户管理 → 包期会员”按周查看每位会员送了多少，本周超额的会员置顶并标红（可切换查看上周、更早的周）；报原来的 4 位编码也能找到；学期结束一键把所有包期会员改回普通会员、编码恢复 4 位（需输入登录密码，操作前自动备份） |
| 经营数据 | 收件单数/件数、取件单数、营业额（开启金额后）、新增客户、在店待取、超期未取；每日趋势、品类分布、各时段忙闲、店员业绩；与上期对比 |
| 品类管理 | 默认 12 个品类：衣物、鞋子、床单、被套、枕头套、毛巾、书包、浴巾、毛毯、凉被、围巾、帽子；可新增、改名、排序、停用、设置单价 |
| 账号管理 | 新增店员/店长、重置密码、停用账号 |
| 系统设置 | 店铺名称、超期天数、金额开关、开单后弹出打印选项、包期会员每周额度、标签（布带宽度、每张长度、编号和姓名的字号，拖动调整位置）、数据备份下载 |
| 打印 | 开单后弹出打印窗口：**全部打印**（每件衣物一张，一次打完）、**打印单张**（点一下打一张，可按顺序“打印下一张”）、整单只打一张；取货页、订单详情也可随时补打。标签用水洗唛布带（默认 30mm 宽、每张 40mm），只打编号和姓名，字号分开调、位置在系统设置里拖动调整，每张末尾可打裁切线；手机开单可由“打印站”电脑自动打印 |

## 权限

| 功能 | 店长 | 店员 |
|---|:---:|:---:|
| 开单、打印 / 补打标签 | ✓ | ✓ |
| 取货 | ✓ | ✓ |
| 修改自己的密码、本机打印设置、打印站 | ✓ | ✓ |
| 订单查询、查看订单详情（店员可确认取件、打印待取订单） | ✓ | ✓ |
| 修改订单、作废、恢复、撤销取件、导出、查询结果的合计金额 | ✓ | |
| 客户管理、包期会员设置、学期结束 | ✓ | |
| 经营数据 | ✓ | |
| 品类管理、账号管理、系统设置、数据备份 | ✓ | |

权限在服务器接口层校验，店员即使知道网址也无法访问店长功能。

## 安装与启动（Windows 电脑）

1. 安装 **Node.js 22 LTS 或更高版本**：<https://nodejs.org/zh-cn>（国内镜像：<https://npmmirror.com/mirrors/node/>），一路“下一步”即可。
2. 把本项目文件夹复制到电脑上，例如 `D:\laundry-system`。
3. 双击 **`start.bat`**。第一次会自动安装依赖（需要联网，约 1 分钟），之后显示：
   ```
   洗衣房管理系统已启动，访问地址：
     http://localhost:3000
     http://192.168.1.23:3000
   ```
   Windows 防火墙弹窗询问时，勾选“专用网络”并点“允许访问”，否则手机连不上。
   `start.bat` 启动的是**正式版**（数据在 `data` 文件夹）；`demo.bat` 是演示版（数据在 `data-demo`，店名带“（演示）”）。
4. 系统启动后会**自动打开一个浏览器窗口**（标题带“直接打印”，打印不弹预览，见下文“连接打印机”），第一次使用会要求**创建店长账号**。也可以在任意浏览器打开 `http://localhost:3000`。
5. 手机连接店里同一个 WiFi，浏览器打开上面 `192.168` 开头的地址。建议在路由器里给这台电脑**固定 IP**，地址就不会变。

也可以用命令行：

```bash
npm config set registry https://registry.npmmirror.com   # 国内网络建议先执行
npm install
npm start
```

**开机自动启动**：按 `Win + R` 输入 `shell:startup` 回车，把 `start.bat` 的快捷方式放进打开的文件夹。

**先试用演示数据**：双击 **`demo.bat`**（或运行 `npm run demo`），会在独立的 `data-demo` 目录生成 45 天示例数据，不影响正式数据。演示账号：店长 `admin / admin123`，店员 `xiaoli / 123456`。演示数据里编码 `8888` 有 3 位客户，可以试试同编码选择；另有 8 位包期会员（如孙一诺 `888107`，报旧编码 `8107` 也能找到），其中有几位本周超额，在“客户管理 → 包期会员”里排在最前面。演示和正式系统用的是同一个端口，请先关掉其中一个窗口再打开另一个。

## 连接打印机

1. **装好驱动**：在电脑上安装标签机驱动（如佳博 GP-1834T，按说明书安装），在 Windows“打印机和扫描仪”中能打印测试页。驱动“打印首选项”的设置见下面“水洗唛布带”。
2. **设置标签**：店长进入“系统设置 → 标签打印”，填布带宽度和每张长度，分别调编号、姓名的字号，在预览上用鼠标或手指拖动编号、姓名到想要的位置（点选后也可以用方向键微调），点“打印一张测试”检查，满意后保存。
3. **每台设备选择打印方式**（“我的 → 本机打印方式”）：
   - 电脑直接连着打印机：选“本机直接打印”（电脑默认）。
   - 手机开单：选“发送到打印站”（手机默认），并在连着打印机的电脑上打开“打印站”页面点“开启打印站”。开启后这台电脑在任何页面都会在后台自动打印手机发来的标签，重启浏览器后自动继续。
   - 同一时间只能有一台设备作为打印站，其他设备开启时会提示，需要确认“接管”。打印站领取任务后要确认打印完成，万一中途断网、关机，没打出来的标签会自动重新排队，不会丢失。
4. **不弹打印预览、直接打印（强烈推荐）**：
   - 把标签打印机设为 Windows **默认打印机**：在“设置 → 打印机和扫描仪”里先关掉“让 Windows 管理默认打印机”，再点标签打印机 → “设为默认值”。
   - 双击 `start.bat` 启动系统后，会自动用一个单独的 Edge 窗口（没有 Edge 时用 Chrome）打开系统，**窗口标题带“直接打印”**。在这个窗口里点打印直接出标签，不再弹打印预览；第一次打开需要登录一次。
   - 在平时的浏览器窗口里打印仍会弹出预览，打印窗口里也会提示。“直接打印”窗口关掉了，双击 **`open-direct-print.bat`** 可以重新打开。
   - “直接打印”窗口里打印的任何东西都会直接送到默认打印机，打印其他文件请用平时的浏览器窗口。
   - 也可以手动设置：右键浏览器快捷方式 → 属性 → “目标”末尾加一个空格和 `--kiosk-printing`。Edge 关掉窗口后常常还在后台运行，要先在 Edge 设置的“系统和性能”里关掉“启动增强”和“关闭 Microsoft Edge 后继续运行后台扩展和应用”，关闭所有 Edge 窗口后再用这个快捷方式打开才会生效。

打印出来有空白页或位置偏移：确认驱动里的纸张尺寸与系统设置一致；在打印对话框中把“边距”设为“无”、缩放设为 100%；再到系统设置里拖动微调编号、姓名的位置。

### 水洗唛布带（如佳博 GP-1834T + 30mm 宽布带）

- **系统设置 → 标签打印**：布带宽度默认 30mm，“每张长度”填剪下来一张标签的长度（默认 40mm）。标签只打编号和姓名，字号分开调，位置在预览上拖动设置；默认在每张末尾打一条裁切虚线，沿虚线剪开即可。
- 每张长度大于布带宽度时，文字会自动转 90°，沿布带方向排列，剪下后横着看就是设置页预览的样子。
- **驱动“打印首选项”**：纸张宽 30mm、高 = 每张长度（如 30 × 40mm，宽和高不要填反）；介质类型选“连续”（整卷布带不分段）；打印方式选“热转印”，布标请用**树脂碳带**，水洗后字迹才不会掉。
- 打出来空白：检查碳带是否装好、涂层面是否朝向布带；字太淡：调高驱动里的浓度、降低打印速度。

## 数据与备份

- 全部数据保存在 `data/laundry.db` 一个文件中。
- 每天自动备份到 `data/backups/`，保留最近 30 天。
- 店长可在“系统设置 → 数据备份”随时下载一份，建议每周拷到 U 盘或网盘。
- **恢复备份**：关闭系统 → 删除 `data/laundry.db-wal`、`data/laundry.db-shm` → 用备份文件替换 `data/laundry.db` → 重新启动。
- **升级程序**：保留 `data` 文件夹，替换其他文件后重新启动即可，数据库结构会自动升级。
- **忘记密码**：在电脑上运行 `npm run reset-password -- 用户名 新密码`。

## 部署到云服务器（可选）

想在店外也能看数据，可以部署到阿里云 / 腾讯云等服务器，步骤相同（`npm install`、`npm start`），并在安全组放行端口。建议：

- 用 `pm2` 保持后台运行：`npm i -g pm2 && pm2 start npm --name laundry -- start && pm2 save && pm2 startup`
- 用 nginx 反向代理并配置 HTTPS（国内服务器使用域名需要备案）
- 打印站照样可用：店里连着打印机的电脑用浏览器登录云端地址并开启打印站即可

可用环境变量：`PORT`（端口，默认 3000）、`HOST`（默认 0.0.0.0）、`DATA_DIR`（数据目录，默认 data）、`APP_TIMEZONE`（默认 Asia/Shanghai）。

## 开发

```bash
npm run dev     # 修改服务端代码后自动重启
npm test        # 接口集成测试（使用临时数据目录，不影响正式数据）
```

技术栈：Node.js 22 + Express 5 + 内置 SQLite（`node:sqlite`，无需编译，运行时只依赖 Express）；前端 Vue 3.5 + Vue Router 4（免构建，已放在 `public/vendor`，直接修改 `public/js` 下的文件刷新浏览器即可）。

```
server/                 服务端
  index.js              入口：路由、静态文件
  db.js                 数据库连接、建表（自动迁移）、默认品类
  auth.js               密码加密、登录会话、权限中间件
  settings.js           系统设置
  backup.js             自动备份、数据清理
  services/             客户、订单的公共逻辑
  routes/               各模块接口：auth / customers / categories / orders / print / stats / users / settings
public/                 前端
  index.html
  vendor/               Vue、Vue Router（本地文件，不走 CDN）
  css/app.css           样式（电脑侧边栏 / 手机底部导航自适应）
  js/main.js            路由、页面框架
  js/print.js           标签生成与打印
  js/station.js         打印站（后台领取打印任务）
  js/components/        通用组件：客户选择、品类选择、订单列表、图表等
  js/views/             各页面
scripts/demo.js         演示数据
scripts/reset-password.js  重置密码
test/api.test.js        接口测试
docs/开发计划.md         需求整理、设计与实现计划
```
