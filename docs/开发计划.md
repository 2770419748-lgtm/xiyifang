# 洗衣房管理系统 · 开发计划（一期）

## 一、需求整理

| # | 需求 | 实现方式 |
|---|---|---|
| 1 | 手机和电脑都可以操作 | 响应式网页：电脑左侧菜单，手机底部导航；同一个网址，无需安装 App |
| 2 | 客户送衣服登记姓名和编码，编码 4 位或 6 位 | 开单页输入编码 + 姓名，前后端都校验 `^(\d{4}\|\d{6})$`；编码可多人共用，同一编码有多位客户时弹出姓名选择；同名客户可以有不同编码 |
| 3 | 可以通过姓名和编码模糊搜索 | 开单（联想老客户）、取货、订单查询、客户管理四处都支持模糊搜索 |
| 4 | 品类分类管理（12 类） | 默认：衣物、鞋子、床单、被套、枕头套、毛巾、书包、浴巾、毛毯、凉被、围巾、帽子；店长可增改、排序、停用 |
| 5 | 登记送来时间和取走时间 | 开单/取件时自动记录当前时间（可修改），并记录开单人、取件经办人 |
| 6 | 连接现有打印机打印姓名和编号 | 浏览器打印 + 精确纸张尺寸（水洗唛布带）；“打印站”让手机开单也能由电脑出标签；支持静默打印（`open-direct-print.bat` 用 `--kiosk-printing` 打开浏览器，不弹打印预览） |
| 7 | 看到经营数据 | 收件/取件/营业额/新客户/在店/超期、每日趋势、品类分布、时段分布、店员业绩、环比 |
| 8 | 查询：客户什么时间送来了什么、什么时候取走 | 订单查询（多条件 + 导出）、客户详情页的完整送取记录、订单详情时间线 |
| 9 | 登录系统；店长全部权限，店员只能开单和取货 | 账号登录 + 两种角色，权限在接口层校验 |
| 10 | 包期会员：每周（周一至周日，按送件时间）衣物和浴巾合计 9 件、鞋子 1 双；开单不提示超额，周末查看哪些会员超额，超额的置顶；包期会员编码前加 88；学期结束一键降级、编码恢复 4 位，需输入登录密码 | 客户增加会员类型和原编码；每周额度按“额度项”设置，一项可包含多个品类、合并计算；“客户管理 → 包期会员”按周统计每位会员每项额度的件数，超额的排在最前面并标红，可切换上一周；学期结束校验当前账号密码，批量恢复并自动备份 |

## 二、技术方案

```
手机浏览器 ─┐
            ├─ 店里 WiFi ─→ 店里电脑：Node.js 服务（Express） ─→ SQLite 数据文件 data/laundry.db
电脑浏览器 ─┘                     │
                                  └─ 打印站页面 → 标签打印机（USB/网口，装好驱动）
```

- **后端**：Node.js 22 + Express 5 + 内置 `node:sqlite`。不需要单独安装数据库，不需要编译原生模块（国内装依赖不容易出错）。
- **前端**：Vue 3 + Vue Router 全局版本，免构建；所有资源从本机提供，不依赖外网 CDN。
- **部署**：店里一台电脑运行（双击 `start.bat`），手机连同一 WiFi 访问；也可部署到云服务器。
- **安全**：密码 scrypt 加盐存储；登录用 HttpOnly Cookie；写操作校验自定义请求头防跨站伪造；登录失败次数限制。
- **数据安全**：WAL 模式；每天自动备份（保留 30 天）；店长可下载备份。

### 打印方案

1. 标签只用水洗唛布带：按布带宽度和每张长度生成（`@page { size: 宽mm 长mm }`），只打编号和姓名；两者的位置（中心点，占标签宽高的百分比）和字号分开保存，在系统设置里拖动预览设置，过长自动缩小。每张长度大于布带宽度时内容自动转 90° 沿布带方向排列；可在每张末尾打裁切虚线。
2. 内容可选：店名、送来时间、物品明细、单号与件数、备注。
3. 开单只负责开单，成功后弹出打印窗口：**全部打印**（每件衣物一张，如“衣物 1/3”，一次打完）、**打印单张**（每件一个按钮，点一下打一张，打过的打勾；也可连续点“打印下一张”）、整单只打一张。取货页、订单详情的“打印”使用同一个窗口。
4. 打印方式按设备设置：
   - **本机直接打印**：电脑连着打印机，开单后直接调用打印。
   - **发送到打印站**：手机开单后把任务发到服务器；连着打印机的电脑开启“打印站”后通过长轮询实时领取并打印（切到其他页面或在后台也能打印）。
   - 打印任务流程为“领取 → 打印 → 确认完成”，领取后 60 秒未确认会重新排队，保证不丢标签；同一时间只允许一台打印站，换设备需确认接管。
5. Chrome/Edge 加 `--kiosk-printing` 启动参数，实现不弹对话框直接出纸。

## 三、数据库设计

| 表 | 主要字段 |
|---|---|
| users 账号 | 用户名（不区分大小写，唯一）、密码哈希、姓名、角色 manager/clerk、启用状态、最后登录 |
| sessions 登录会话 | 令牌哈希、用户、过期时间（30 天，使用中自动续期） |
| customers 客户 | 姓名、编码（4/6 位，可多人共用）、电话、备注、会员类型（普通/包期）、原编码（包期前的 4 位）、成为会员时间 |
| categories 品类 | 名称、排序、默认单价（分）、启用 |
| orders 订单 | 单号、客户、状态（待取/已取/已作废）、件数、金额（分）、备注、送来时间、取走时间、开单人、取件人、作废信息 |
| order_items 订单明细 | 订单、品类、数量、成交单价 |
| print_jobs 打印任务 | 订单、打印内容（全部/单张第几件/整单）、状态（待打印/打印中/已完成/已跳过）、创建/领取/打印时间、领取设备 |
| settings 系统设置 | 店名、金额开关、超期天数、开单后弹出打印选项、包期每周额度（额度项，可多个品类合并计算）、标签设置 |

- 单号格式：`送来日期-当日流水号`，如 `261022-007`。
- 时间统一按店铺时区（默认北京时间）存为 `YYYY-MM-DD HH:mm:ss`。
- 金额以“分”为单位存整数，避免小数误差。

## 七、默认决策（可按实际情况调整）

- **编码可重复**：一个编码可以对应多位客户（如同一宿舍）。输完编码后若有多位客户，弹出姓名让店员选择，也可以选“新客户”用同一编码登记；同一姓名也可以有不同编码。
- **金额**：默认关闭；开启后按品类单价自动计算，可手动改金额（优惠），经营数据统计营业额。
- **取货**：按整单取件；可一次取同一客户的多单。
- **改单**：店员开单后不能修改；修改、作废、撤销取件由店长操作。
- **超期**：按自然日计算，送来满 7 天仍未取算超期（可设置）。
- **包期会员**：额度按自然周（周一至周日）、以送来时间归属，作废的订单不算；同一项额度里的品类合并计算（默认衣物 + 浴巾合计 9 件、鞋子 1 双），没放进任何一项的品类不在包期内；开单、改单都不提示超额，店长在“客户管理 → 包期会员”按周查看，超额的置顶（超得多的在前）；开启金额时，包期会员开单时包期内的品类不收费，其他品类按单价计算；只有 4 位编码的客户可以设为包期会员（编码变为 88 + 4 位）；学期结束需输入当前登录账号的密码。
